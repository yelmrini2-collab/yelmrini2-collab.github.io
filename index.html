Noya Publisher

Noya Publisher est un outil interne de Noya Agencies qui permet de planifier et de publier des vidéos sur les comptes TikTok gérés par l'agence, à partir de fichiers stockés sur Google Drive.

Fonctionnement

  • Le titulaire du compte TikTok autorise l'application via la connexion officielle TikTok (Login Kit).
  • Les vidéos sont planifiées dans un tableau de pilotage puis envoyées à TikTok via la Content Posting API officielle.
  • Le statut de chaque publication est suivi et consigné.
